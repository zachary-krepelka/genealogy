## Introduction

This repository contains scripts for processing genealogical data to produce a
variety of deliverables including family tree diagrams, family reunion
invitations, and birthday calenders.  Example datasets centering on the lineages
of some household names in American popular culture will be found under the
`data` directory.  Data is stored in a custom [JSON][1] structure.
